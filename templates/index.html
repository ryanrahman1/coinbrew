Coinbrew API

Fast, clean, self-hosted crypto market backend

Overview

Welcome to the Coinbrew API — a RESTful service for managing coins, users, and trading data. Below you'll find all public and authenticated endpoints. Authenticated endpoints require Bearer token authentication or session cookies.

Authentication

POST /api/v2/auth/register
Register a new user account. Creates auth user and user record with $1,500 starting balance.
Body: username (string), email (string), password (string)
Returns: Access token, refresh token (also set as httpOnly cookies)
POST /api/v2/auth/login
Login with existing credentials. Returns session tokens.
Body: email (string), password (string)
Returns: Access token, refresh token (also set as httpOnly cookies)
POST /api/v2/auth/refresh
Refresh authentication tokens using refresh token from cookies.
Cookie: refresh_token (httpOnly)
Returns: New access and refresh tokens

Coins

GET /api/v2/coins
Get a paginated, filterable, and sortable list of all coins.
Query: min_price (float, optional), limit (int, default=20), offset (int, default=0), sort_by (string, default="current_price"), order (asc|desc, default="desc")
Returns: Array of coin objects
GET /api/v2/coins/{symbol}
Fetch detailed information for a specific coin by its symbol (e.g., BTC, ETH).
Path: symbol (string, required, case-insensitive)
Returns: Single coin object with all properties
GET /api/v2/coins/{symbol}/history
Get historical price data for a specific coin over time.
Path: symbol (string, required)
Query: time_range (12h | 24h | 1w | max, default="7d")
Returns: Object with history array containing timestamp/price pairs
GET /api/v2/coins/search
Search for coins by name or symbol using fuzzy matching (case-insensitive).
Query: query (string, required) - Search term
Returns: Array of matching coin objects
POST /api/v2/coins/create
Create a new coin with Fair Launch settings (1M supply, $0.001 initial price). Requires authentication. Supports optional image upload (max 5MB, PNG/JPG only).
Auth: Bearer token required
Form Data: name (string, required), symbol (string, required), file (image file, optional)
Returns: Created coin object with public image URL

Users

GET /api/v2/user/me
Get complete information for the currently authenticated user, including email and balance.
Auth: Bearer token required
Returns: User object with id, username, email, balance, created_at
GET /api/v2/user/{user_id}/profile
Fetch a user's full profile including portfolio holdings and recent trade history. Email is hidden unless viewing your own profile.
Auth: Bearer token required
Path: user_id (string, required) - User UUID
Returns: Object with user info, portfolio (holdings array + total value), and recent_trades array (limit 10)

Trading

POST /api/v2/trade/buy
Execute a buy trade. Deducts balance, adds holdings, and records the transaction.
Auth: Bearer token required
Body: coin_symbol (string, required), amount (float, required), price_per_coin (float, required)
Validates: Sufficient balance, coin exists
Returns: Trade confirmation with transaction details
POST /api/v2/trade/sell
Execute a sell trade. Validates holdings, reduces holdings, adds to balance, and records transaction.
Auth: Bearer token required
Body: coin_symbol (string, required), amount (float, required), price_per_coin (float, required)
Validates: Sufficient holdings to sell
Returns: Trade confirmation with transaction details

Market

GET /api/v2/market/top
Get top or bottom performing coins ranked by market capitalization.
Query: limit (int, default=10) - Number of coins to return, order (asc|desc, default="desc")
Returns: Object with coins array containing market cap and all coin details
GET /api/v2/market/leaderboard
Get top users ranked by total portfolio value (balance + holdings).
Query: limit (int, default=10) - Number of users to return
Returns: Object with leaderboard array containing username and total_value
GET /api/v2/market/recent-trades
Get recent global trades with pagination and optional filtering by coin symbol.
Query: limit (int, default=10, max=100), offset (int, default=0), symbol (string, optional) - Filter by coin symbol
Returns: Object with trades array including coin info, buyer/seller usernames, amount, price, and timestamp

Public

GET /api/v2/public/stats
Get general API statistics including user count, coin count, total trades, and endpoint usage metrics.
Auth: None required
Returns: Stats object with total counts, total requests, top 5 endpoints by usage, and timestamp
GET /api/v2/public/health
Health check endpoint confirming server and database connectivity.
Auth: None required
Returns: Status object with service health, version, database status, and timestamp

Admin (Protected)

POST /api/v2/admin/update-market
Recalculate prices for all coins based on recent trade activity. Uses dynamic pricing algorithm with ±30% volatility cap.
Auth: Admin API key required (X-Admin-Key header)
Returns: Count of coins updated
POST /api/v2/admin/recalculate-marketcap
Recalculate market capitalization for all coins (price × circulating supply).
Auth: Admin API key required (X-Admin-Key header)
Returns: Success confirmation message
POST /api/v2/admin/refresh-coin/{symbol}
Force price and history update for a specific coin.
Auth: Admin API key required (X-Admin-Key header)
Path: symbol (string, required) - Coin symbol to refresh
Returns: Success message with new calculated price
GET /api/v2/admin/status
Admin status check to verify admin routes are operational.
Auth: Admin API key required (X-Admin-Key header)
Returns: Status message and timestamp

Authentication

Most endpoints require authentication. Include the Bearer token in the Authorization header:

Authorization: Bearer YOUR_ACCESS_TOKEN

Alternatively, tokens are stored in httpOnly cookies after login/register.

Admin endpoints require an additional admin API key:

X-Admin-Key: YOUR_ADMIN_KEY

Error Example

{
  "detail": "Coin not found"
}

Common error codes: 400 (Bad Request), 401 (Unauthorized), 404 (Not Found), 500 (Internal Server Error)
